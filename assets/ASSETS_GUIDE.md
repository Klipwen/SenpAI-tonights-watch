## 3. What You DO NOT Need to Download (Handled Automatically by Code)

1. **Anime Posters & Covers:**
   * **Do NOT download these manually!**
   * The **Jikan API tool** automatically fetches official, high-definition anime poster URLs directly from MyAnimeList for whichever anime SenpAI recommends.
2. **Number Icons (1, 2, 3) & Badges:**
   * **Do NOT use emojis or image numbers!**
   * We will style sleek, minimalist CSS numbered badges (e.g. clean dark-mode circular badges with white numerals `1`, `2`, `3`). They look bespoke, sharp, and avoid any generic AI appearance.
3. **UI Elements & Buttons:**
   * **STRICT ZERO EMOJI POLICY:** All buttons and controls will use clean, human-crafted typography (e.g., `Add to Watchlist`, `Compare`, `Clear List`, `Find Similar`) and subtle SVG line icons if needed—never emoji icons.
